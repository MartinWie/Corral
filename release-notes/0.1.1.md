- Sessions saved without their conversation find it again by title when Corral starts
- Menus and the empty window show only the agents installed on this Mac; Settings shows the others greyed out
- ⌘W closes Settings and the About window, never the session behind them
- Opening Corral a second time brings the running one to the front
- The window opens at full size on first launch
- A shorter prompt for installing the status hooks, and a Remove button for them in Settings › Agents

Agents and scripts can start other sessions in Corral, watch them and answer their prompts.

- New `corral` command, the app itself behind `~/.local/bin/corral`: spawn a session with a model, a prompt and a folder, wait for what it does, approve or deny its permission prompts, send follow-ups, read its answer, follow every state change with `corral events`
- Off until you turn it on in Settings › Agents › Command line, where the skill for Claude Code and OpenCode is installed too
- Models per agent in Settings › Agents: Easy, Medium and High, and the tier new sessions start on
- Scripts get the outcome as exit status or JSON; a started session hands back a result with `corral report`
- Sidebar folders from the command line: create, move sessions, collapse, rename, delete
- Claude's "trust this folder?" question now shows as needs input instead of sitting unnoticed
- Optional, in the same settings: a standing addition to the prompts of started sessions, closing finished started sessions after a while, notifying only when one fails or waits, and `corral stats` for token use and wasted effort per session
- A session started by another one is marked with ↳ in the sidebar
- Collapsing or expanding a folder from outside the sidebar updates it
